# Repository tools

Run tools from the repository root after `uv sync --frozen`.

- `uv run --no-sync python tools/check_version_tag.py` checks the installed
  distribution and runtime version against `pyproject.toml`. When `GITHUB_REF`
  is a tag, it also checks that tag. It never creates tags.
- `uv run --no-sync python tools/check_artifacts.py dist/*.whl dist/*.tar.gz`
  installs each built artifact into its own fresh temporary environment and
  checks version reporting, `py.typed`, core imports and optional dependency
  boundaries. It uses `uv` and downloads base runtime dependencies; it never
  contacts Telegram or requires Redis.

Build first with `uv build`. Security reports are generated by CI and are not
source-controlled. Publishing is a separate maintainer action.
