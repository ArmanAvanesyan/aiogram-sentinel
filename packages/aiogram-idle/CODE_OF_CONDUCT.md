# Code of conduct

Contributors and maintainers should treat each other respectfully. Discuss ideas
and code on their merits, welcome questions and differing experience, and give
specific, constructive feedback.

Harassment, threats, discriminatory language, personal attacks and disclosure of
someone else's private information are not acceptable in project spaces.

Maintainers may edit or remove inappropriate contributions and restrict access
when needed to protect participants. Report conduct concerns privately through
the contact information on the [maintainer's GitHub profile](https://github.com/ArmanAvanesyan),
sharing only the information needed to investigate. Maintainers should handle
reports discreetly and consider context when deciding a response.
