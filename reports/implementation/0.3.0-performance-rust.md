## Loader and wheel CI review fixes

Optional loading now normalizes dynamic-loader OSError and rejects non-exact ABI
identity types or missing CPU callables before translator callbacks or effects.
Four regression cases cover Boolean/float ABI values, absent kernels and loader
failure. The actual generated wheels are installed on matching platform runners:
Linux glibc/macOS/Windows across Python3.10–3.14, and both musl architectures in
matching Alpine containers across those Python versions. Smoke tests exercise
profile resolution, command validation, raw hashing and compiled batch hashing.
The runtime matrix downloads those exact artifacts rather than rebuilding native
source. Local platform smoke passes; other platform runs remain CI verification.

## Serial qualification decision: native withheld

Root serial ABBA qualification failed: selected compiled batch 100 commands /
10 profiles / 30 targets native/Python CPU ratio 1.56666 (56.7% slower); dynamic
confirmation-hit 1/10 p95 ratios 1.1578/1.2001. Several end-to-end tails had more
than 10% repeat spread, so no universal tail-latency claim is supported. The
original failed gate stands. No native publication, native tag or dependency
extra is authorized by this result. Source remains buildable. Python 0.3.0 can
release independently. Supplemental compiled manager confirmation-hit and
fake-network workloads were added without replacing original gate workloads.
