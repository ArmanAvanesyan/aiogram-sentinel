# Idle 0.2.1 correctness patch

The first prepared navigation view can now be explicitly abandoned before any
screen has been committed. The combined projection retains the existing
authoritative session generation and absolute expiry; later navigation reuses
that generation. Wrong-generation abandonment and expired rendering still reject,
and explicit abandonment retains uncertain rendering checkpoints.

Runtime configuration now rejects differences in backend-owned retention and
storage capacities with actionable field names. Polling/concurrency and other
worker settings can still differ. Overloaded errors expose optional payload-free
capacity diagnostics while preserving ordinary Exception argument behavior.

The Redis READ script now observes namespace/configuration history, parked state
and fresh server TIME atomically. Commit-time history, configuration, lease and
ownership fences remain in place. Warm reads use one EVALSHA exchange, without
separate GET/TIME/HEXISTS commands. Redis clock diagnostics distinguish server
sampling from monotonic interpolation. Receipt retention remains unchanged:
expired completed receipts prune lazily; promised replay is never evicted early.
