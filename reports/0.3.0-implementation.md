extensions. Python is the default engine. Rust selection requires the exact 0.3.0,
ABI 1 companion and fails before initialization if unavailable or incompatible.
No mutation failure triggers a fallback to Python.

## Performance evidence and limits

The driver separates measured result rows from diagnostics, records seed and
installed-distribution provenance, and emits raw CPU and latency arrays. Exploratory
real-Redis measurements reported 4 library round trips for combined no-op updates,
17 for tracked adoption and 9 for standalone activity updates, including coordination.
Those are diagnostics, not latency or native speedup qualification. The serial
artifact-based CPU/p95 gate is evaluated separately; no speedup is claimed here.

Memory remains single-process and non-durable. Redis requires the documented
single-primary deployment, persistence/eviction guarantees and verified coordinator.
Business callbacks, Telegram requests, external authorities and independent stores
are not part of a Redis transaction. Superseded inline prompt stripping is best
effort after committed activity; durable overlay restore remains a guarded stage.

Migration conservatively retains one original source backup when opaque retention
cannot be proven. Interrupted canonical staging remains bounded and resumable;
unknown/protected evidence is never automatically discarded. Missing promised rows
fail closed, and a whole old backup is never restored over newer writes.

Native publication and measured performance qualification remain independent release
gates. Durable analytics outboxes, multi-primary Redis, automatic external-business
retries from unknown history, and application-specific flow implementations remain
outside this package.
